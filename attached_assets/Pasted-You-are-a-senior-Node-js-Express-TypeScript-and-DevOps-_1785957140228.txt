My backend returns HTTP 500 from `/ai/generate`, but my logs only show:

* request errored

The actual exception is not being logged.

Instrument the backend so the original exception is always logged before returning HTTP 500.

* Express routes

## Error Logging

Every catch block must log:

* Full stack trace
* Error name
* Error message
* File
* Line number (when available)
* Request ID
* Provider name
* HTTP response from provider
* Response body from provider

Example:

```ts
try {
   ...
} catch (error) {
   logger.error({
      requestId,
      provider,
      errorName: error.name,
      errorMessage: error.message,
      stack: error.stack,
      response: error.response?.data,
      status: error.status
   });

   throw error;
}
```

Do not replace the error with a generic message.
